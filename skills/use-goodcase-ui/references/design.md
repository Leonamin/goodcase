# Goodcase reference design

## 목적

좋은 기본 동작과 디자인을 가진 컴포넌트를 직접 조작하고, 동작 계약을 확인한 뒤 다른 프로젝트로 가져간다. 참조 디자인을 그대로 쓸 수도 있고 프로젝트 토큰에 연결해 재구성할 수도 있다.

## 디자인 원본

실행 토큰의 원본은 assets/src/styles/tokens.css다. 따뜻한 중립 배경, 흰 표면, 읽기 쉬운 잉크색, 파란 강조색을 기본으로 한다. Forest는 강조색을 녹색으로 바꾸며 기본 테마와 같은 모서리를 유지한다. Compact는 컨트롤 높이와 간격을 줄인다. 토큰을 추가·수정할 때 CSS에서 값을 중복 정의하지 않는다.

## 계층과 배치

갤러리는 목록 탐색용 사이드바, 선택 항목 제목, 네 문서 탭, 조작 캔버스로 구성한다. 모바일에서는 목록을 열고 닫는 패널로 전환한다. 제품 컴포넌트에는 갤러리 레이아웃을 결합하지 않는다.

## 계약

마우스·키보드·터치에서 핵심 기능에 접근할 수 있게 한다. 의미 있는 HTML을 먼저 사용하고 모달·선택·메뉴의 복잡한 접근성 동작은 Radix로 구현한다. 오류는 텍스트와 색상을 함께 제공하고 입력값을 임의로 폐기하지 않는다. 처리 상태는 실제 callback 결과로 결정한다. 데모 시뮬레이션은 예제에 명시한다.

## 이식

색상·타이포·간격·모서리·밀도는 변경 가능하다. 선택 확정, Escape 취소, 포커스 복귀, 중복 실행 차단, 실패 후 재시도 등 동작 계약은 보존한다. 요구로 계약을 변경하면 assets/src/catalog 메타데이터와 예제, 관련 테스트도 갱신한다.
