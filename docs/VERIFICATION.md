## 손가락 추종 뷰어·중앙 축소 눌림

사용자 후속 요청으로 이미지 변경의 240ms 자동 슬라이드를 제거했다. 버튼·썸네일·키보드는 즉시 전환한다. 화면 맞춤 상태의 touch/pen은 이미지와 중앙 빈 배경에서 좌우 스와이프할 수 있으며 현재·인접 페이지가 손가락을 따라 움직인다. 충분한 거리/플릭은 전환, 짧거나 세로·취소된 제스처는 복귀한다. 확대 상태에서는 pan만 처리한다. isAnimated는 놓기 후 180ms 위치 보정만 제어하며 false/모션 감소에서도 직접 추종은 유지한다.

탐색 버튼의 배치 transform을 공통 active transform이 덮어써 31px 이동하고 pointerup이 배경으로 바뀌는 오류를 실제 브라우저에서 재현했다. 넓은 고정 클릭 영역으로 수정하고 빈 공간 닫기는 실제 빈 공간에서 시작/종료한 탭으로 제한했다. 일반 버튼 눌림은 중앙 96% scale/80ms로 변경하고 배치 transform을 유지한다. 뷰어 탐색은 고정 클릭 영역 안쪽 표시만 축소해 가장자리 클릭도 동작한다.

전체 Playwright 64개 통과. 실제 CDP touch 추종·양방향 전환·짧은/세로/cancel·확대 pan·빈 공간 스와이프/탭, 1440/375 탐색 버튼 가장자리 1px에서 180ms 누름 후 실제 index 변경, 원래 CSS를 주입한 31px 위치 튐 검출을 확인했다. 모달 재개 테스트는 이미지 성공/100% 준비 후 제스처를 보내도록 수정하고 동일 결과 assertion을 유지했다. 5개 worker에서 반복 5회 통과했다. TypeScript·앱·Storybook 빌드 통과. 모바일 스와이프 중 실제 화면 캡처에서 두 페이지 추종 표시 확인.

## 모바일 핀치 확대·축소

두 손가락의 거리와 중심을 기준으로 100~400% 확대·축소를 추가했다. 핀치를 시작하면 페이지 스와이프를 취소하고, 확대 상태의 한 손가락은 이미지 이동만 처리한다. 핀치에서 한 손가락만 남으면 현재 위치로 이동 기준을 다시 잡아 점프 없이 이어간다. 100%로 돌아와도 같은 터치 흐름에서는 페이지 전환을 막고, 모두 뗀 뒤 새 제스처부터 스와이프를 허용한다. 핀치 종료·취소는 배경 닫기를 유발하지 않는다.

전체 Playwright 70개 통과. 실제 Chromium CDP 두 손가락 입력을 사용한 핀치 테스트 3개와 독립 감사 3개는 배율 경계, 중심 밖 콘텐츠 지점 유지, 스와이프에서 핀치 전환, 한 손가락 이동으로의 연속성, 페이지·닫기 충돌 방지와 새 제스처 복구를 확인한다. 테스트의 touchEnd 인수는 종료할 손가락을 지정하도록 실제 이벤트 추적으로 확인했다. TypeScript·앱·Storybook 정적 빌드 통과.
