# Goodcase

Use Conventional Commits for any commits. Inspect staged diff first. Boolean names use is/has/can/should/needs prefixes. Reusable UI lives in src/components; catalog demos never belong in reusable files. All visuals consume --gc-* tokens. Component events are external boundaries; never import gallery or project services into reusable UI. Keep contract metadata aligned with implementation. Browser demos of async work must clearly label local simulation. Do not deploy without user request.
